# Карта проекта — tutu-swipe

Свайп-подбор путешествий поверх MCP Туту. Хакатон Туту, защита 19–20 августа 2026.

Начало для агента — `AGENTS.md`. Этот файл отвечает на вопрос «где что лежит».

---

## Навигация по задаче

| Вопрос | Куда идти |
|---|---|
| Что делать прямо сейчас | `npm run features next`, затем `SPEC_PLAN/phase-registry.md` |
| Как устроена работа и ревью | `docs/EXECUTION_RULES.md` |
| Что нельзя нарушать | `SPEC_PLAN/CONSTITUTION.md` |
| Что уже сделано | `PROGRESS.md` |
| Что передаётся следующей сессии | `HANDOFF.md` |

## Код

| Каталог | Ответственность |
|---|---|
| `src/app/` | Экраны и маршруты API |
| `src/lib/mcp/` | Клиент MCP, обёртки инструментов, типы ответов |
| `src/lib/discovery/` | Разбор запроса, каталог направлений, отбор кандидатов |
| `src/lib/search/` | Веерный поиск, потоковый контракт, бюджет времени |
| `src/lib/packages/` | Сборка поездок, цены, предупреждения |
| `src/lib/ranking/` | Признаки, ранжировщик, разнообразие |
| `src/lib/explain/` | Объяснения из агрегатов реакций |
| `src/lib/link/` | Кодирование и разбор подборки в ссылке |
| `scripts/check-boundaries.mjs` | Архитектурные границы как исполняемая проверка |
| `tests/fixtures/` | Записанные ответы MCP для детерминированных тестов |

Направление зависимостей и запреты на импорт — в `SPEC_PLAN/ARCHITECTURE.md`.

## Как менять активную фазу

1. Все пункты Definition of Done текущей фазы отмечены.
2. `npm run check` зелёный, при необходимости `npm run smoke`.
3. Фичи фазы в `docs/features.json` в состоянии `passing` с одобренным ревью.
4. `PROGRESS.md` и `HANDOFF.md` обновлены.
5. Здесь меняется активная фаза и её статус.

Перевод фазы в активную без выполнения пунктов 1–4 — нарушение правила 25 конституции.

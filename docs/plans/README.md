# Планы фич

Один файл — одна фича. Имя: `YYYY-MM-DD-краткое-название.md`.

Первая строка каждого плана — статус:

```
> status: active | done | superseded — почему | archive
```

План содержит: цель, декомпозицию на задачи, критерии приёмки каждой задачи
(команда, которая должна пройти), затронутые файлы и обязательную секцию
**«Не входит в объём»**.

Последняя секция — не формальность: она заранее выравнивает исполнителя
и ревьюера, чтобы работа не отвергалась по предсказуемым причинам вроде
«а почему не сделал ещё и это».

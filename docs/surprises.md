# Сюрпризы

Сюда пишется только то, что агент НЕ может вывести из общих знаний:
странные решения, обходные пути, неочевидные ограничения, опасные места.

Не пиши сюда, что такое Next.js или как работает Postgres — это общие знания.
Тест для каждой записи: **что сломается у следующей сессии, если она этого
не знает?** Нет ответа — записи здесь не место.

Формат:

```
## Короткий заголовок
Что неочевидно, почему так сделано, чего нельзя трогать.
Дата, ссылка на коммит или файл.
```

## У MCP Туту серверный кэш: холодное направление отвечает в 10 раз дольше

Замер 2026-08-04, `search_multitransport` Москва → Сочи на 2026-09-10:

| Вызов | Время |
|---|---|
| первый (холодный) | 10.8 с |
| повтор | 0.48 с |
| повтор | 1.53 с |
| `search_hotels` Сочи | 2.1 с |

Из этого следует главное решение по производительности: **бюджет в 3 секунды до первой карточки достижим только по прогретым направлениям**. Прогревать нужно не свой кэш, а чужой — достаточно заранее дёрнуть поиск по каталогу направлений, и сервер Туту начнёт отвечать быстро.

Что сломается, если это забыть: кто-нибудь начнёт строить сложный собственный кэш ради скорости, хотя рычаг находится на стороне Туту. И демо на незнакомом направлении будет ждать десять секунд при полностью исправном коде.

Перед защитой прогрев каталога обязателен. Насколько долго держится их кэш — не выяснено, проверить до хакатона.

## Полезная нагрузка ответа лежит строкой внутри `content[0].text`

Ответ инструмента приходит не структурой, а текстом в `result.content[0].text`, который надо разбирать как JSON отдельно. Схемы входа инструментов сервер отдаёт, схем ответа — нет: структура описана только в текстовых инструкциях `get_<domain>_instructions`.

Что сломается: попытка типизировать ответ по схеме инструмента. Типы пишутся по фактическим ответам и держатся в `tests/fixtures/`.

## Размеры, которые определяют форму ссылки на подборку

`checkout_ref` одного транспортного варианта — 546 байт, 14 полей (замер 2026-08-04). Три поездки с жильём — порядка 2,5 КБ, в кодировке для URL около 3,4 КБ.

Поэтому в ссылку кладутся параметры поиска и идентификаторы, а не сами предложения: страница подборки пересобирает варианты через MCP при открытии. Побочная выгода — цены на открытой ссылке свежие, а не месячной давности.

Что сломается, если сделать иначе: длинная ссылка режется мессенджерами, а сохранённые цены протухают молча.

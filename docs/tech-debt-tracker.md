# Технический долг

Отслеживаемый долг допустим, скрытый — нет. Запись делается в момент отклада, а не потом.

Формат: что отложено · почему · когда вернуться · чем грозит.

---

## Открыто

| Что | Почему отложено | Когда вернуться | Чем грозит |
|---|---|---|---|
| Брендированные подборки под маркетинговые спецпроекты | Вне области PRD, упоминается на защите как продолжение | После хакатона | Нет |
| Голосовое управление фильтрами | Вне области PRD | После хакатона | Нет |
| Сессия не переносится между устройствами | Внешнего хранилища нет по ограничению проекта | При развитии продукта | Начатый подбор теряется при смене устройства |
| Замена карточки в потоке рассчитана на один переход «снапшот → живая» | Учёт ведётся по идентификаторам снапшотных событий; сейчас каждый кандидат обрабатывается один раз, поэтому дублей нет | Когда появится «показать ещё варианты по городу» | Вторая живая карточка по тому же направлению добавится рядом вместо замены |
| Модель считает веса независимыми (диагональная ковариация) | Полная ковариация требует матричных операций и на 10-15 наблюдениях за сессию всё равно не оценивается — выбрано в KTD5 | При появлении реальных данных о пользователях | Корреляции между признаками (например, цена и звёзды) не учитываются |
